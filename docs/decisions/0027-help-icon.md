# ADR-0027 草の図の右下に、配布プロジェクトへのヘルプのアイコンを置く

**2026-10-08、Issue #232。**

## 文脈

- 草の図 (`graph/grass.ts` が描く 4 つの形。ADR-0026) は、プロフィールページ (ADR-0025) や README に図だけで貼られる。
  見た人には、何の図か・どう読むか・どう導入するかへ辿る手がかりが無い
- 説明と導入の手順は配布プロジェクト [`/cosense-grass`](https://scrapbox.io/cosense-grass/) にある (ADR-0005)
- **`<img>` で貼られた SVG の中のリンクは押せない。** 画像そのものを開けば効く (research §3)。Cosense で画像を押すと拡大のモーダルになり、そこもまだ `<img>`。名前の行のプロジェクト名の `<a href>` も同じ扱い (ADR-0024)
- Cosense に貼る行は、リンクの無いただの画像にしたばかり (ADR-0025 の 2026-10-07 の改訂)

## 決定

### 1. 目的は気づかせることで、リンクは画像を開いた後に効けばよい

- 図の中に丸に `i` のアイコンを描き、`<a href>` で `https://scrapbox.io/cosense-grass/` (`DISTRIBUTION_URL`) へ向ける
- `<img>` の間は押せないことを受け入れる。画像を開けば押せる。Cosense からは、画像 → 拡大のモーダルに出る画像の URL → 開いた SVG のアイコン、の 3 段階 (research §3 の 2026-10-08 の実測)
- **Cosense に貼る行はリンク付きにしない。** 画像全体がヘルプへのリンクになり、画像を開けなくなる。ADR-0025 の改訂も覆さない

### 2. 置き場所は名前の行の高さで、「計」の列の真下

- 横は「計」の列の中央、縦は名前の行の文字の中央 (`nameMiddle`)。直径は 11px で、線だけの丸と、点と棒の `i`
- 名前の行は草の右端 (`gridRight`) で切っているので、計の列の下は空いている。**名前の切り方も外寸 (`GRASS_SIZES`) も変えずに済む**
- 外寸の右下の角には置かない。半年 × 3 分割の下の余白はサムネで切れる前提の余白 (ADR-0024 の帰結) で、そこに置くと最初に切れる
- `i` はフォントに頼らず図形で描く。外部フォントは読めず、OS のフォントで形が揺れる (design §8)
- 色はユーザー名と同じ控えめな灰色 (`theme` で変える)。押せる範囲は透明な四角で絵より広く取り、`<title>` (`lang` で文言を変える) を付ける

### 3. 4 つの形すべてに常に出す

- 名前が無いとき・合算のときも出す。隠すクエリは作らない (要望が出てから足す)
- 説明の図 (`/v1/guide/*.svg`) には出さない。それ自体が説明なので
- リンク先は `lang` によらず同じ (配布プロジェクトは日本語で、英語の説明は Worker のトップにある)

## 却下した案

- **Cosense に貼る行を `[画像 ヘルプのURL]` にする。** 1 回のクリックで飛べるが、画像を開けなくなり、10-07 の改訂を戻すことになる
- **読み方の専用ページを作ってそこへ向ける。** ヘルプとしては直接だが、まず配布プロジェクトのトップで足りると作者が判断した。ページを作ったら `DISTRIBUTION_URL` とは別の定数で向け直せばよい

## 帰結

- 図の本文が変わるので ETag が変わり、共有 SVG のキャッシュが入れ替わる (ADR-0015 決定 2)。`card-golden.test.ts` の答えと README の画像を撮り直す
